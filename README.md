# Blob Soccer ⚽

agar.io 풍의 2D 1:1 축구 게임 (오프라인 초안).

**의존성 0 / 빌드 0.** `index.html` 하나를 브라우저로 열면 바로 실행됩니다.

## 실행

```bash
# 1) 가장 빠른 방법 — 파일 그냥 열기
xdg-open index.html      # macOS: open index.html / Windows: start index.html

# 2) 로컬 서버로 열고 싶다면 (선택)
python3 -m http.server 8000   # → http://localhost:8000
```

## 조작 (아주 단순)

| | 이동 | 대시 |
|---|---|---|
| **P1** | `W A S D` | `Space` (또는 `좌Shift`, `F`) |
| **P2** | `방향키` | `Enter` (또는 `우Shift`, `/`) |

- AI 대전에서는 `WASD` / `방향키` 둘 다 P1 조작으로 쓸 수 있습니다.
- **대시**: 순간 가속 + 공을 훨씬 강하게 차고 상대를 밀어냅니다. 쿨타임 1.5초 (선수 주변 흰 링이 게이지).
- 메뉴: `1` AI 대전 / `2` 같은 PC 2인 대전 · 경기 중 `ESC` 메뉴 · 종료 후 `R` 재시작

## 규칙

- 경기 시간 150초, 시간 종료 시 더 많이 넣은 쪽 승리 (동점이면 무승부).
- 득점 후 1.6초 연출 → 킥오프. 실점한 쪽으로 공이 살짝 치우쳐 놓입니다.
- 골포스트는 원형 충돌체라서 맞고 튀어나옵니다.

## 구조

전부 `index.html` 안에 있습니다 (약 600줄).

- `CFG` — 필드 크기, 가속도/마찰, 대시 파워·쿨타임, 경기 시간 등 **밸런스 값 전부 여기 모아둠**
- `updatePlayer` / `updateBall` — 이동·감속·벽 반사·골 판정
- `collidePlayerBall` / `collidePlayers` — 질량 비(선수 5 : 공 1) 기반 임펄스 충돌
- `botInput` — AI. 공의 미래 위치 예측 → 상대 골 반대편으로 돌아 들어가기, 우리 진영으로 굴러오면 골라인에서 차단, 자책골 위험 시 측면으로 걷어내기
- 렌더는 Canvas 2D. 논리 해상도 1280×800을 창 크기에 맞춰 스케일하므로 어떤 창 크기에서도 필드 전체가 보입니다.
- 고정 타임스텝(120Hz) 시뮬레이션 + 가변 프레임 렌더 → 모니터 주사율과 무관하게 동일한 물리.
- 사운드는 WebAudio로 즉석 생성 (에셋 파일 없음).

## 다음 단계 (온라인)

물리가 이미 고정 타임스텝으로 분리돼 있어서 그대로 서버로 옮길 수 있습니다.

1. `ws` + Node로 권위 서버 하나 (방 = 플레이어 2명, 60Hz 틱).
2. 클라이언트는 입력(방향 2비트 + 대시 1비트)만 전송, 서버가 스냅샷 브로드캐스트.
3. 클라이언트는 스냅샷 보간 + 자기 캐릭터만 예측(prediction) — 지금 `updatePlayer`를 그대로 재사용.
